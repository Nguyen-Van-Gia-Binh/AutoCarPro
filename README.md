# AutoCarPro (AutoWashPro)

A professional management system for car wash and auto care services.

## Tech Stack
- **Backend:** Java (Maven)
- **Database:** MySQL / SQL Server
- **IDE:** NetBeans / IntelliJ IDEA

## Getting Started

### Prerequisites
- JDK 17 or higher
- Maven 3.6+
- Database server running

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Nguyen-Van-Gia-Binh/AutoCarPro.git
   ```
2. Navigate to the project directory:
   ```bash
   cd AutoWashPro
   ```
3. Build the project:
   ```bash
   mvn clean install
   ```
4. Run the application.
